# 완료된 기준 모델의 중간 결과

2026년 11월 27일에 서버의 summary.json을 다시 읽었다.
각 행은 seed 42와 43 및 44에서 얻은 결과의 평균이다.
각 실행의 epoch는 검증 macro-F1으로 선택했다.
테스트 결과를 보고 모델을 다시 선택하지 않았다.
모든 수치는 백분율이다.

| 방법 | 검증 macro-F1 | 테스트 정확도 | 테스트 macro-F1 | 테스트 오탐률 | 테스트 카메라 재현율 |
| --- | ---: | ---: | ---: | ---: | ---: |
| MobileNet에서 전체 사진을 사용한다. | 96.91 | 96.51 | 96.51 | 2.58 | 95.60 |
| MobileNet에서 안경을 확대한다. | 98.13 | 98.00 | 98.00 | 1.07 | 97.07 |
| MobileCLIP의 특징을 고정하고 선형 분류기를 학습한다. | 95.22 | 95.67 | 95.67 | 2.67 | 94.00 |
| MobileCLIP의 이미지 인코더도 미세조정한다. | 99.09 | 98.00 | 98.00 | 1.42 | 97.42 |

안경을 확대한 MobileNet은 전체 사진을 사용하는 조건보다 좋았다.
MobileCLIP을 미세조정하면 특징을 고정한 조건보다 좋았다.
그러나 테스트 F1은 안경을 확대한 MobileNet과 거의 같았다.
현재 결과만으로 MobileCLIP이 더 좋다고 주장하지 않는다.
오탐률의 평균은 안경을 확대한 MobileNet에서 더 낮았다.
통계적 유의성은 아직 검정하지 않았다.

이 결과는 합성 착용 이미지에서 측정했다.
분할 사이에 인물 그룹은 겹치지 않는다.
같은 안경 제품은 여러 분할에 등장한다.
따라서 새로운 제품이나 실제 착용 환경에서의 성능을 입증하지 않는다.
이 결과는 촬영용 카메라 렌즈를 구분했다는 근거도 아니다.

## 중단과 재개

MobileCLIP 실행 6개는 완료됐다.
이후 matched_global의 첫 실행이 지역 입력의 valid 값 없이 호출됐다.
대조군에서 이 값을 참조한 코드 때문에 학습이 실패했다.
실패는 첫 epoch의 결과를 저장하기 전에 발생했다.
이 실패로 인해 후속 실험의 기록 검사도 실패했다.
따라서 zero-shot과 Tip-Adapter의 결과는 아직 없다.

수정한 코드는 72c70a5다.
대조군은 전역 입력만으로 지역 가중치의 0 배열을 만들도록 수정했다.
실제 학습 호출을 재현하는 회귀 검사를 추가했다.
전체 검사 26개가 통과했다.
실패한 실행의 기록은 별도 폴더에 보존했다.
완료된 MobileCLIP 실행은 덮어쓰지 않는다.
나머지 실행은 glasses-proposed-study-r2-20261127.service에서 재개했다.
후속 실행은 glasses-presentation-adaptation-r2-20261127.service에서 대기한다.
부위별 구조가 개선됐다는 판단은 나머지 9개 실행이 끝난 뒤에 한다.

실제 카메라의 평가와 Nano에서의 측정은 아직 남아 있다.
