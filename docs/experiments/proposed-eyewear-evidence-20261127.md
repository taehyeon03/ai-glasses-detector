# 기준 모델의 실패를 보완하는 실험

## 목적

기준 모델에서 관측한 문제를 보완하는 구조를 비교한다.
proposed라는 이름을 붙인 것만으로 성능 향상을 주장하지 않는다.
카메라가 달린 안경을 구분하는 과업은 유지한다.
안경의 광학 렌즈와 촬영용 카메라 렌즈를 구분해서 평가한다.
현재 데이터에는 촬영용 렌즈 위치를 표시한 정답이 없다.
자동 영역을 실제 렌즈의 정답으로 사용하지 않는다.

## 현재 확보한 근거

안경 영역을 확대한 MobileNet의 검증 결과가 전체 사진보다 좋았다.
바깥 영역을 가린 조건만으로는 성능이 좋아지지 않았다.
안경 주변을 가렸을 때 분류 점수가 변했다.
중앙에 카메라가 있는 제품에서도 중앙 부위에 민감한 결과가 나왔다.
초기 레이어의 열지도는 머리카락과 배경에도 반응했다.
따라서 높은 분류 점수가 실제 카메라 렌즈를 구분했다는 보장은 없다.

## 사전에 정한 비교 조건

모든 새 실행은 기존의 동일한 안경 crop을 사용한다.
전역 입력은 224×224다.
세 지역 입력은 원본 사진에서 추출한다.
지역 입력은 112×112다.
좌측 외측과 중앙 및 우측 외측을 추정한다.
이 위치는 촬영용 렌즈의 정답이 아니다.
동일한 학습과 검증 및 테스트 분할을 유지한다.
seed는 42와 43과 44다.
학습은 20 epoch 동안 수행한다.
검증 macro-F1으로 epoch를 선택한다.
동점이면 오탐률과 loss를 순서대로 비교한다.
테스트는 선택된 모델에서 한 번 평가한다.
테스트를 보고 모델 구성이나 임계값을 수정하지 않는다.

| 조건 | 설명 | 비교 목적 |
| --- | --- | --- |
| 이전 MobileNet | 기존 crop과 일반 분류기를 사용한다. | 이미 측정한 기준으로 둔다. |
| mobileclip_linear | MobileCLIP-S0의 이미지 특징을 고정하고 선형 분류기를 학습한다. | 사전학습된 표현을 평가한다. |
| mobileclip_finetune | MobileCLIP-S0의 이미지 인코더도 미세조정한다. | CLIP을 고정한 조건에만 비교하는 것을 피한다. |
| matched_global | proposed와 같은 전역 특징 및 분류기를 사용한다. | 바뀐 분류기의 효과를 분리한다. |
| parts_mean | 공유 CNN으로 지역 특징을 구해서 동일하게 결합한다. | 지역 입력을 추가한 효과를 분리한다. |
| parts_gate | 전역 특징과 지역 특징 및 품질값으로 결합 가중치를 학습한다. | 학습한 결합의 효과를 분리한다. |

새로 학습하는 조건은 5개다.
각 조건을 seed 3개로 반복하므로 실행은 총 15개다.
아직 학습한 결합 가중치를 설명의 정답으로 해석하지 않는다.
지역별 제거 실험으로 영향을 별도로 확인해야 한다.

## proposed 후보의 구조

전역 입력과 세 지역 입력이 같은 MobileNet의 특징 추출기를 사용한다.
전역 특징과 지역 특징은 128차원으로 투영한다.
품질값은 선명도와 밝기 및 대비와 얼굴 검출 신뢰도로 구성한다.
품질값이 실제 카메라의 가시성을 뜻하는 것은 아니다.
검출에 실패한 지역은 결합에서 제외한다.
모든 지역이 실패하면 전역 경로만 사용한다.
서로 다른 크기의 입력을 공유하므로 BatchNorm의 통계는 고정한다.
이 조건은 matched_global에도 동일하게 적용한다.
기존 MobileNet과의 차이를 구조만의 효과로 설명하지 않는다.
matched_global과의 비교가 구조의 효과를 확인하는 주된 대조군이다.

## MobileCLIP 기준

[공식 구현](https://github.com/apple-aiml-research/ml-mobileclip)을 사용한다.
소스 revision은 설정에 고정한다.
원본 가중치의 해시를 실행마다 기록한다.
이미지 인코더만 분류에 사용한다.
텍스트 인코더는 학습 후 추론에 필요하지 않다.
공식 S0의 기본 해상도는 256이다.
이번 비교는 입력 크기를 통제하려고 224로 실행한다.
공식 기본 설정의 성능을 재현했다고 부르지 않는다.
MobileCLIP에는 ImageNet의 평균과 표준편차로 정규화하지 않는다.
공식 전처리처럼 0에서 1 사이의 입력을 사용한다.
선형 분류 조건은 추론용으로 재매개변수화한다.
미세조정 조건은 원래의 학습 구조를 사용한다.

## 실제 카메라 평가의 범위

사용자는 현재 카메라 안경의 실물을 확보하지 못했다고 확인했다.
노트북이나 USB 카메라는 사용할 수 있다.
따라서 실제 착용한 카메라 안경의 재현율은 현재 측정할 수 없다.
일반 안경의 오탐률은 실촬영 자료를 확보하면 측정할 수 있다.
카메라 입력부터 결과까지의 지연도 측정할 수 있다.
실제 착용 데이터와 화면을 재촬영한 데이터를 별도 domain으로 기록한다.
화면 재촬영의 결과를 실제 카메라 안경의 착용 성능으로 해석하지 않는다.
인물과 촬영 세션이 학습 및 평가에 겹치지 않도록 한다.
같은 영상의 연속 프레임을 독립적인 검사 횟수로 세지 않는다.
실제 촬영은 사람이 준비한 상태에서 시작해야 한다.
준비 여부를 확인하지 않고 웹캠을 촬영하거나 사진을 저장하지 않는다.

## 촬영용 렌즈를 사용했는지 평가하는 방법

촬영용 카메라의 개구부를 별도로 표시한다.
안경의 광학 렌즈를 별도로 표시한다.
장식용 리벳과 표시등도 구분한다.
카메라가 보이지 않는 사진에는 visibility 상태를 기록한다.
제품 참고 사진에서 카메라 위치를 확인해야 한다.
합성 이미지에서 실제 위치와 형태가 보존됐는지도 확인해야 한다.
촬영용 렌즈를 가린 결과와 장식 부분을 가린 결과를 비교한다.
같은 넓이의 무작위 영역을 가리는 대조군을 둔다.
평가용 주석으로 모델의 가중치를 학습하지 않는다.
부위 감독 학습이 필요하면 학습 분할에 별도 주석을 만든다.
주석이 없으면 이 평가는 pending으로 기록한다.
