# DINO로 분류 근거를 탐색하는 실험

## 가설

사전학습된 DINO의 특징에 카메라 안경을 구분하는 정보가 있을 수 있다.
분류 점수에 대한 기여도는 안경의 힌지나 카메라 부근을 강조할 수 있다.
attention만으로 그 가설을 입증하지 않는다.

## 고정한 조건

공통 데이터의 기존 분할을 유지한다.
일반 안경은 0이다.
카메라가 있는 안경은 1이다.
seed는 42다.
입력은 224×224로 바꾼다.
이미지의 전체 영역을 유지한다.
가로세로 비율은 이 단계에서 정사각형으로 변형된다.
안경의 끝부분이 잘리지 않도록 center crop을 사용하지 않는다.
증강은 사용하지 않는다.
추론 임계값은 0.5로 고정한다.
검증 macro-F1으로 epoch를 선택한다.
동점이면 오탐률을 비교한다.
그래도 같으면 검증 loss를 비교한다.
테스트는 선택된 체크포인트에서 한 번 평가한다.

## 방법

DINO ViT-S/16의 파라미터는 동결한다.
학습 가능한 선형 분류기를 추가한다.
분류기는 최대 30 epoch 동안 학습한다.
이 단계는 DINO 자체를 미세조정하는 실험이 아니다.
동결한 backbone의 attention은 분류기 학습으로 변하지 않는다.
결과는 이 조합의 의존성을 설명한다.
카메라 유무를 판별하는 보편적인 특징을 입증하지는 않는다.

검증 데이터에서 정답과 예측의 조합마다 앞의 두 사례를 선택한다.
빈 조합이 있으면 앞의 미선택 사례로 채운다.
최대 8장에 Integrated Gradients를 적용한다.
설명할 점수는 예측한 클래스의 logit에서 다른 클래스의 logit을 뺀 값이다.
이미지 평균에 해당하는 기준 입력을 사용한다.
흐리게 만든 기준 입력도 비교한다.
최초 실행은 사다리꼴 근사를 사용했다.
단색 기준 입력에서는 큰 적분 오차가 관측됐다.
최초 그림을 신뢰할 수 있는 기여도로 해석하지 않는다.
후속 분석은 Gauss-Legendre 구적법을 사용한다.
오차가 기준을 넘으면 계산점을 최대 512개로 늘린다.
오차 기준은 `absolute_error / max(abs(score_delta), 1) <= 0.02`다.
기준을 넘긴 그림은 reliable=false로 기록한다.
근사 오차는 completeness 차이로 기록한다.
기준 입력이 바뀔 때 상위 영역이 유지되는지도 기록한다.

기여도가 높은 패치부터 5%와 10%와 20%를 가린다.
각 조건에서 같은 면적을 무작위로 가리는 대조군을 10번 측정한다.
가린 부분은 각 기준 입력의 픽셀로 바꾼다.
분류 margin이 얼마나 감소하는지 저장한다.
가림 자체가 원래 데이터와 다른 입력을 만들 수 있다.
따라서 가림 결과만으로도 인과를 확정하지 않는다.

## 산출물과 후속 실험

공통 로그에 학습과 검증과 테스트의 평가를 남긴다.
attention과 기여도를 별도 배열로 저장한다.
검증 이미지의 오분류 사례를 보존한다.
얼굴이 들어간 결과는 공개 Git에 올리지 않는다.
관찰한 영역을 사람이 확인한 뒤 ROI를 정하는 후속 실험을 설계한다.
ROI를 사용한 모델은 전체 이미지를 사용한 모델과 같은 분할로 비교한다.
머리카락이나 생성 표식을 사용하는 경우도 실패 사례로 기록한다.
현재 encoder를 Nano의 최종 모델로 확정하지 않는다.
배포 후보는 이후 경량 모델과 비교한다.
실제 Nano에서의 구동은 pending이다.

## 완료한 실행

실행 ID는 `dino-vits16-probe-20261127-s42`다.
학습 코드의 commit은 `976e22d`다.
학습 시작 시 작업 트리는 깨끗했다.
학습부터 최초 설명 생성까지 약 421초가 걸렸다.
최종 체크포인트는 epoch 23에서 선택됐다.
학습 가능한 분류기의 파라미터는 770개다.
동결한 DINO의 파라미터는 21,665,664개다.

| 학습 | 0.135315 | 95.09% | 95.08% | 6.94% | 97.11% |

| 테스트 | 0.114810 | 96.07% | 96.07% | 3.87% | 96.00% |

테스트 혼동행렬은 `[[721, 29], [30, 720]]`이다.
행은 정답이다.
열은 예측이다.
순서는 일반 안경과 카메라 안경이다.
테스트에서 일반 안경 29장을 카메라 안경으로 오인했다.
카메라 안경 30장을 놓쳤다.
테스트는 한 번 평가했다.
검증 분할에는 인물 그룹이 3개뿐이다.
테스트 분할에도 인물 그룹이 3개뿐이다.
검증보다 테스트 점수가 높다는 결과만으로 일반화 성능을 단정하지 않는다.
이전 YOLO 실험과는 데이터가 다르다.
두 실험의 수치를 동일한 조건에서 얻은 비교로 해석하지 않는다.

## 기여도를 보정한 결과

별도 분석의 commit은 `5c34370`이다.
같은 체크포인트로 약 60초 동안 기여도를 다시 계산했다.
학습과 테스트 평가는 반복하지 않았다.
계산점을 최대 256개까지 늘려 수치 기준을 충족했다.
8장에 두 기준 입력을 적용한 총 16건이 오차 검사를 통과했다.
가장 큰 scaled error는 약 1.58%였다.
`reliable`은 이 수치 검사에 통과했다는 뜻이다.
설명이 인과적으로 옳다는 뜻은 아니다.

상위 20개 패치는 전체 196개 패치의 약 10.2%다.
다음 값은 예측한 클래스의 margin이 감소한 양이다.
확률이 감소한 비율은 아니다.

| 가린 부분을 채운 기준 입력 | 높은 기여도를 가진 패치를 가린 평균 | 무작위 패치를 가린 평균 |
| --- | ---: | ---: |
| 이미지 평균 | 3.811 | 0.186 |
| 흐린 이미지 | 5.204 | 0.046 |

각 조건은 검증 이미지 8장에 적용했다.
각 이미지의 무작위 대조군은 10번 측정했다.
8장 모두에서 높은 기여도를 가진 패치를 가린 영향이 더 컸다.
이 표본은 정답과 예측의 조합마다 앞의 두 사례를 뽑은 것이다.
전체 데이터에 대한 통계적 추정으로 해석하지 않는다.
기준 입력을 바꿀 때 상위 20개 패치의 일치율은 평균 43.75%였다.
따라서 세부 부위의 순위는 기준 입력에 영향을 받는다.

확인한 그림에서는 안경 주변이 분류 점수에 기여했다.
일부 배경과 얼굴의 다른 부위에도 기여가 나타났다.
일반 안경을 카메라 안경으로 오인한 그림에서도 안경 주변에 기여가 나타났다.
안경을 보고 있다는 사실만으로 카메라 유무를 올바르게 판단한다고 볼 수는 없다.
현재 결과만으로 카메라 렌즈에만 집중한다고 결론 내리지 않는다.
다음 비교 후보는 안경테와 양쪽 힌지를 포함하는 ROI다.
ROI를 사용한 경량 모델과 전체 이미지를 사용한 경량 모델을 같은 분할로 비교해야 한다.
