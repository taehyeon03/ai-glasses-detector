# DINO로 분류 근거를 탐색하는 실험

## 가설

사전학습된 DINO의 특징에 카메라 안경을 구분하는 정보가 있을 수 있다.
분류 점수에 대한 기여도는 안경의 힌지나 카메라 부근을 강조할 수 있다.
attention만으로 그 가설을 입증하지 않는다.

## 고정한 조건

공통 데이터의 기존 분할을 유지한다.
일반 안경은 0이다.
카메라가 있는 안경은 1이다.
seed는 42다.
입력은 224×224로 바꾼다.
이미지의 전체 영역을 유지한다.
가로세로 비율은 이 단계에서 정사각형으로 변형된다.
안경의 끝부분이 잘리지 않도록 center crop을 사용하지 않는다.
증강은 사용하지 않는다.
추론 임계값은 0.5로 고정한다.
검증 macro-F1으로 epoch를 선택한다.
동점이면 오탐률을 비교한다.
그래도 같으면 검증 loss를 비교한다.
테스트는 선택된 체크포인트에서 한 번 평가한다.

## 방법

DINO ViT-S/16의 파라미터는 동결한다.
학습 가능한 선형 분류기를 추가한다.
분류기는 최대 30 epoch 동안 학습한다.
이 단계는 DINO 자체를 미세조정하는 실험이 아니다.
동결한 backbone의 attention은 분류기 학습으로 변하지 않는다.
결과는 이 조합의 의존성을 설명한다.
카메라 유무를 판별하는 보편적인 특징을 입증하지는 않는다.

검증 데이터에서 정답과 예측의 조합마다 앞의 두 사례를 선택한다.
빈 조합이 있으면 앞의 미선택 사례로 채운다.
최대 8장에 Integrated Gradients를 적용한다.
설명할 점수는 예측한 클래스의 logit에서 다른 클래스의 logit을 뺀 값이다.
이미지 평균에 해당하는 기준 입력을 사용한다.
흐리게 만든 기준 입력도 비교한다.
적분에는 사다리꼴 근사를 사용한다.
근사 오차는 completeness 차이로 기록한다.
기준 입력이 바뀔 때 상위 영역이 유지되는지도 기록한다.

기여도가 높은 패치부터 5%와 10%와 20%를 가린다.
각 조건에서 같은 면적을 무작위로 가리는 대조군을 10번 측정한다.
가린 부분은 각 기준 입력의 픽셀로 바꾼다.
분류 margin이 얼마나 감소하는지 저장한다.
가림 자체가 원래 데이터와 다른 입력을 만들 수 있다.
따라서 가림 결과만으로도 인과를 확정하지 않는다.

## 산출물과 후속 실험

공통 로그에 학습과 검증과 테스트의 평가를 남긴다.
attention과 기여도를 별도 배열로 저장한다.
검증 이미지의 오분류 사례를 보존한다.
얼굴이 들어간 결과는 공개 Git에 올리지 않는다.
관찰한 영역을 사람이 확인한 뒤 ROI를 정하는 후속 실험을 설계한다.
ROI를 사용한 모델은 전체 이미지를 사용한 모델과 같은 분할로 비교한다.
머리카락이나 생성 표식을 사용하는 경우도 실패 사례로 기록한다.
현재 encoder를 Nano의 최종 모델로 확정하지 않는다.
배포 후보는 이후 경량 모델과 비교한다.
실제 Nano에서의 구동은 pending이다.
