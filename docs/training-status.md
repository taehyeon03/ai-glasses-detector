## 학습 산출물 위치

실제 학습 산출물은 SSD 원본 작업 폴더에 보관되어 있다.

`/mnt/data/ai-glasses-tryon/work/yolo10_20261104`

- 완료 실험: 390개
- 보존된 체크포인트: `best.pt`와 `last.pt` 391쌍
- 실험별 설정·결과·Weights & Biases 기록이 함께 보존됨

공개 저장소에는 얼굴 이미지와 대용량 가중치를 넣지 않는다. 이미지 권리·개인정보 검토와 배포 용량 정책을 정한 뒤, 필요한 가중치만 별도 배포한다.

## 선택된 베이스라인

| 항목 | 확인된 내용 |
| --- | --- |
| 선택 실험 | `exp_0013_n_320_band_combo_s44` |
| 모델 | YOLO26 nano classification |
| 시작 가중치 | `yolo26n-cls.pt` |
| 과업 | AI 안경 / 일반 안경 이진 이미지 분류 |
| 입력·증강 | 320 px, band crop, combo augmentation |
| 학습 설정 | batch 32, learning rate 0.0001, seed 44, 최대 100 epoch, patience 25 |
| 실행 환경 | RTX 5070 Ti |

`-cls` 모델은 이미지 전체를 분류한다. 안경 위치를 표시하는 객체 검출 모델은 아니므로, YOLOE 기반 ROI 추출과 MobileCLIP 비교는 후속 실험 후보로 구분한다.

## 선택 방법과 고정 테스트 결과

구성은 4개 seed의 검증 balanced accuracy 평균으로 선택하고, 동점이면 false positive rate를 비교했다. 고정 테스트 세트는 모델 선택에 사용하지 않았다.

| 고정 테스트 | 결과 |
| --- | --- |
| 이미지 수 | 200장 |
| 정확도 | 82.5% |
| balanced accuracy | 82.5% |
| AI 안경 재현율 | 96.0% |
| 일반 안경 오탐률 | 31.0% |
| AI 안경 F1 | 84.6% |
| 혼동행렬 | `[[69, 31], [4, 96]]` |

테스트 이미지는 모두 합성 이미지다. 실제 착용 사진과 현장 FPS는 아직 측정하지 않았으므로, 실환경 성능으로 일반화해서는 안 된다.

- 완료·확인됨: YOLO26n 이진 분류 실험 390개, 체크포인트, 합성 고정 테스트 결과
- 진행 중: Jetson Nano 배포
- 검증 전: 실제 착용 사진 성능, 현장 FPS, 객체 위치 검출 성능
